A single-line roast of my fridge, written by a program. `main.ts` (Node 22,
stdlib-only, deterministic) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> My fridge hums one tired note, guards a yoghurt from 2019 like a family heirloom, and calls itself an appliance — it's a museum whose only working exhibit is the lightbulb.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
